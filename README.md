# Семейный образовательный портал

Семейный портал подготовки к поступлению в ведущие вузы России. Статический сайт, работает на GitHub Pages, без бэкенда. Прогресс, заметки и результаты тестов хранятся в браузере (localStorage) с экспортом и импортом JSON.

Данные исследования собраны **9 августа 2026 года**.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Дашборд: ближайшие дедлайны, прогресс по планам, резервное копирование |
| `plan.html` | Стратегия по каждому ребёнку, стартовый план на 6 недель, недельный ритм, календарь года, принципы для родителя |
| `tasks.html` | Недельные наборы заданий: 8 недель, авторские задачи с подсказками и разборами |
| `tracker.html` | Метрики недели, дневник интересов, журнал проб, свои задачи, чек-листы |
| `olympiads.html` | Каталог олимпиад с фильтрами, календарь сезона, как работают льготы, индивидуальные достижения |
| `admission.html` | Рейтинги вузов, проходные баллы, ДВИ, целевое обучение, СУНЦ и лицеи, правила приёма 2026 |
| `resources.html` | Каталог образовательных ресурсов с фильтрами, метрики прогресса |
| `tests.html` | Интерактивные тесты RIASEC и «Профиль», чек-лист наблюдения, валидные методики |
| `ai.html` | Исследования по ИИ в обучении, домашние правила по возрасту, инструменты, 10 промптов |
| `strategy.html` | Тренды рынка труда, профессии будущего, устойчивые ядра, мета-навыки |

## Как выложить на GitHub Pages

### Вариант A — через веб-интерфейс, без установки чего-либо

1. Зайдите на [github.com/new](https://github.com/new), создайте репозиторий, например `obrazovanie`. Можно приватный — GitHub Pages для приватных репозиториев доступен на платных тарифах; для бесплатного нужен публичный.
2. На странице репозитория нажмите **Add file → Upload files**, перетащите туда **всё содержимое** этой папки (включая папки `assets` и `data`, и файл `.nojekyll`).
3. Нажмите **Commit changes**.
4. Перейдите в **Settings → Pages**. В разделе *Build and deployment* выберите Source: **Deploy from a branch**, Branch: **main**, папка: **/ (root)**. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/obrazovanie/`.

> Файл `.nojekyll` нужен обязательно: без него GitHub Pages пытается обработать сайт через Jekyll и может игнорировать некоторые файлы.

### Вариант B — через командную строку

```bash
cd путь/к/этой/папке
git init
git add .
git commit -m "Образовательный портал: первая версия"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/obrazovanie.git
git push -u origin main
```

Затем шаг 4 из варианта A.

### Локальный запуск

Просто откройте `index.html` двойным щелчком — сайт работает без сервера. Данные хранятся отдельно для локальной версии и для версии на GitHub Pages (браузер считает их разными сайтами), поэтому выберите что-то одно как основное.

## Как обновлять содержание

Всё содержание вынесено в папку `data/` — это обычные JavaScript-файлы, их можно править в любом текстовом редакторе.

| Файл | Что править |
|---|---|
| `data/deadlines.js` | Календарь дат. Поле `approx:true` означает «дата по прошлому сезону» и рисует звёздочку |
| `data/olympiads.js` | Каталог олимпиад |
| `data/resources.js` | Каталог ресурсов. `star:true` поднимает запись наверх и помечает ★ |
| `data/plans.js` | Планы детей: стратегия, задачи, недельный ритм, календарь года |
| `data/prompts.js` | Промпты для ИИ |
| `data/tests.js` | Утверждения тестов и описания типов |
| `data/tasks.js` | Недельные наборы заданий |
| `data/config.js` | **Имена детей.** Задаются по падежам в одном месте; в текстах стоят токены `{{U}}`, `{{Yg}}` и т.п. |

**Важно:** у задач в `plans.js` первый элемент — идентификатор (`'u-zftsh'`). Если его изменить, галочка «выполнено» для этой задачи потеряется. Добавлять новые задачи безопасно, менять id существующих — нет.

## Имена детей и приватность

Репозиторий публичный — иначе GitHub Pages не работает бесплатно. Поэтому по умолчанию в `data/config.js` стоят нейтральные обозначения («Дочь», «Сын»), а на всех страницах — `<meta name="robots" content="noindex,nofollow">` плюс `robots.txt`, запрещающий индексацию.

Если хотите видеть настоящие имена — впишите их по падежам в `data/config.js` **в локальной копии** на диске и не коммитьте этот файл. Подстановка на всех страницах произойдёт автоматически, править больше ничего не нужно.

Учтите: noindex просит поисковики не индексировать страницу, но не закрывает её от того, кто знает прямую ссылку. Ничего, что не должно попасть к посторонним, в публичный репозиторий класть не стоит. Прогресс, заметки и результаты тестов туда и не попадают — они живут только в браузере.

## Резервное копирование

Прогресс живёт только в браузере. Если почистить историю или сменить устройство — данные пропадут.

Раз в месяц: **Дашборд → Скачать копию (JSON)**, и положить файл в папку проекта на Яндекс.Диске. Восстановление — кнопка «Загрузить копию» там же.

## Что нужно перепроверить

Правила приёма, перечни олимпиад и сроки меняются ежегодно. Ключевые точки сверки:

- **Сентябрь–октябрь 2026** — приказ Минобрнауки о перечне олимпиад на 2026/27. Уровни могут измениться, часть олимпиад выпадет из-за нового Порядка (приказ № 16 от 16.01.2026: очные финалы, порог 500 участников и 25 регионов)
- **Сентябрь–ноябрь 2026** — календари олимпиад на новый сезон у организаторов
- **К 1 ноября 2026** — правила приёма вузов на 2027 год
- **Ноябрь 2026** — приказ Минпросвещения о расписании заключительного этапа ВсОШ

Основные источники: [olimpiada.ru](https://olimpiada.ru/), [rsr-olymp.ru](https://rsr-olymp.ru/docs), сайты приёмных комиссий вузов.
