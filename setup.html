Напоминания и приложение

Портал сам по себе ничего не напомнит — в него нужно зайти. Здесь настраивается обратное: чтобы даты приходили к вам, а не вы к ним. Пятнадцать минут один раз, дальше работает само.

Честно о надёжности каналов. Ни один канал не покрывает всё, поэтому их два. Календарь показывает даты в контексте вашего дня и работает на всех устройствах — но подписные календари обновляются с задержкой, а Google для чужих календарей часто игнорирует встроенные напоминания. Телеграм — наоборот: приходит точно и вовремя, но живёт отдельно от расписания. Вместе они закрывают дыры друг друга.

1. Иконка на телефоне

Портал устанавливается как приложение: иконка на домашнем экране, открывается на весь экран без адресной строки, работает без интернета (последняя загруженная версия). Магазины приложений не нужны, обновляется само.

iPhone и iPad

Открыть портал в Safari (в Chrome на iPhone установка не работает) → кнопка «Поделиться» внизу → «На экран „Домой“» → «Добавить».

Android

Открыть в Chrome → меню из трёх точек → «Установить приложение» или «Добавить на главный экран». Часто Chrome предлагает сам — кнопка выше появится, если браузер готов установить.

Поставьте на телефоны всем четверым. Детям это единственный способ не терять ссылку.

2. Календарь: даты приходят в телефон сами

Все даты портала — олимпиады, кружки, лагеря, подача документов — опубликованы отдельным файлом-календарём. На него подписываются один раз: дальше новые даты появляются сами, а изменённые обновляются. Каждое событие помечено, чьё оно, и содержит ссылку на сайт организатора.

webcal://cheremisin.github.io/jbqye7itb8dg/edu.ics Подписаться
iPhone

Нажать «Подписаться» выше прямо с телефона — откроется календарь, подтвердить. Либо вручную: Настройки → Приложения → Календарь → Учётные записи → Добавить учётную запись → Другое → Подписной календарь, вставить адрес.

Важно: в настройках подписки не включайте «Удалить напоминания» — иначе пропадут уведомления за неделю и за день.

Android и Google

С телефона не получится — только с компьютера: calendar.google.com → «Другие календари» → «+» → «Подписаться по URL», вставить адрес (в Google вставляйте https:// вместо webcal://). Дальше календарь появится и в приложении на телефоне.

Google обычно не показывает уведомления по подписным календарям и обновляет их раз в сутки и реже. Даты видно, напоминания — из Телеграма.

Яндекс Календарь

calendar.yandex.ru → «Добавить календарь» → «Подписаться на календарь» → вставить адрес с https://. Удобно, если семья уже живёт в Яндексе.

Прямая ссылка на файл: edu.ics. Внутри все событий с напоминаниями за 7 дней и за 1 день до даты.

3. Телеграм: утренний дайджест

Бот раз в день пишет в семейный чат, что горит: сегодня, на этой неделе и что закрывается в ближайшие две недели — отдельно по каждому ребёнку. По понедельникам — сводка недели. Это тот канал, который реально доходит.

Работает бесплатно и без сервера: расписание запускает GitHub, он же читает даты портала и отправляет сообщение. Ничего не нужно держать включённым.

Два шага, которые могу сделать только вы — они требуют ввода пароля и токена, а этого я не делаю. Пятнадцать минут.

1
Создать бота
В Телеграме найти @BotFather → команда /newbot → придумать имя и адрес (например, edu_family_bot). В ответ придёт строка вида 8123456789:AAF... — это токен, никому его не показывайте.
2
Создать семейный чат и добавить бота
Группа с вами, женой и детьми → добавить туда бота. Затем узнать номер чата: добавить в группу @getmyid_bot или @RawDataBot, он пришлёт chat id (у групп он отрицательный, например -1001234567890), после чего этого бота удалить.
3
Положить токен в настройки репозитория
GitHub → репозиторий портала → Settings → Secrets and variables → Actions → New repository secret. Создать два: TG_TOKEN (строка от BotFather) и TG_CHAT (номер чата). Секреты зашифрованы и в коде не видны, даже если репозиторий публичный.
4
Проверить
GitHub → вкладка Actions → «Телеграм-дайджест» → Run workflow. Если сообщение пришло в чат — всё, дальше он будет приходить каждое утро сам.

Расписание и текст сообщения настраиваются в файле .github/workflows/digest.yml и tools/telegram-digest.js — скажите, если захотите другое время или другую периодичность.

4. Синхронизация: один прогресс на всех устройствах

Сейчас отметки о выполнении, дневник интересов и результаты тестов лежат в том браузере, где их поставили. С телефона не видно, что отмечено на ноутбуке, и вы не видите, что отметили дети. Это главное ограничение портала.

Решение — маленькая бесплатная база. Каждый заходит по своему коду, данные видны на всех устройствах, вы видите прогресс детей. Хранится только то, что уже хранится сейчас: галочки, заметки, результаты тестов.

Что нужно от вас: завести бесплатный проект на supabase.com (регистрация через GitHub, одна кнопка) и прислать мне два значения из настроек проекта — адрес и публичный ключ anon. Этот ключ по своему назначению публичный, его специально кладут в код сайта. Всё остальное сделаю я.

Состояние: синхронизация выключена

Пока не настроено — работает как раньше: данные в браузере, резервная копия кнопкой на дашборде. Раз в месяц скачивайте её, это две секунды.

Как это устроено и что может сломаться

Календарь
Файл edu.ics пересобирается автоматически при каждом изменении дат на портале. Что ломается: календари обновляют подписку не сразу — Apple раз в час-сутки, Google до суток и дольше. Для срочного «завтра дедлайн» полагайтесь на Телеграм.
Приложение
Обычный сайт плюс сервис-воркер: держит копию страниц в телефоне. Что ломается: после обновления портала телефон может показать старую версию до перезагрузки страницы. Потянуть страницу вниз — обновится.
Телеграм
GitHub запускает скрипт по расписанию. Что ломается: бесплатное расписание GitHub иногда опаздывает на 10–60 минут — для утреннего дайджеста это незаметно. Если репозиторий не трогать больше 60 дней, GitHub отключает расписание и присылает письмо — достаточно нажать кнопку в письме.
Приватность
Календарь лежит по тому же неугадываемому адресу, что и портал, и содержит нейтральные обозначения детей, а не имена. Тот, у кого есть ссылка, видит и портал, и календарь — это осознанный размен, о котором мы договорились.
